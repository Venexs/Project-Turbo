# Project Turbo

### A First Step Into Large-Scale Game Development

**Project Turbo** is one of my earliest large-scale game development projects, built using Unity.

What started as an ambitious attempt at creating a substantial game became an important learning experience in game development, project architecture, asset management, and working with a full-scale game engine.

Looking back, it was a project that was fairly ambitious for my experience and age at the time. While it may not represent the standard of my current work, it represents an important milestone in my development as a programmer and game developer.

---

## About the Project

Project Turbo was an early attempt at tackling game development on a larger scale rather than limiting myself to small experiments or isolated programming exercises.

The project uses Unity and its associated development ecosystem, with a structured project containing assets, packages, project settings, documentation, and testing resources.

It represents an early exploration of what goes into developing and maintaining a larger game project.

## Built With

- **Unity** – Primary game development engine.
- **C#** – Primary scripting language associated with the Unity project.
- **Unity Packages** – Engine extensions and supporting development tools.
- **Git** – Version control and project management.

## Project Structure

The repository contains the following major directories:

| Directory | Purpose |
|---|---|
| `Assets/` | Game assets and project resources |
| `Packages/` | Unity packages and dependencies |
| `ProjectSettings/` | Unity project configuration |
| `Tests/` | Project testing resources |
| `Documentation~/` | Project documentation |
| `.yamato/` | Build and automation configuration |

Additional files include the solution files, contribution documentation, changelog, and licensing information.

## Getting Started

### Requirements

- Unity Hub
- A compatible Unity Editor version
- Git (recommended)

### Opening the Project

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Navigate to the cloned `Project-Turbo` directory.
5. Open the project using its compatible Unity Editor version.
6. Allow Unity to import the project assets and packages.

**Note:** Use the Unity version specified in `ProjectSettings/ProjectVersion.txt` to avoid unnecessary compatibility issues.

## Development Status

Project Turbo is primarily preserved as an earlier game development project and a record of my progress as a developer.

It should be viewed in the context of when it was originally developed, rather than as a representation of my current development standards.

## A Personal Note

Every developer has a project that makes them realise just how much goes into building something substantial.

For me, Project Turbo was one of those projects.

It was my first real attempt at large-scale game development. I learned through experimentation, mistakes, and the process of trying to bring something ambitious to life.

It might not be perfect, but it is a project worth keeping.
